# Проверка страницы и скриншот для сдачи

1. В терминале VS Code из папки проекта выполните `make serve`.
2. Откройте `http://localhost:8000` в обычном браузере.
3. Дождитесь текста игры и активного поля «Ваш ответ».
4. По одному отправьте: `NO`, `NO`, `1`, `1`, `2,4`, `7`, `6`, `2`.
5. Сделайте скриншот окна на Mac: Shift+Command+4, затем выделите область страницы. При необходимости прокрутите терминал внутри страницы, чтобы был виден результат выстрела.
6. Сохраните картинку как `evidence/web-desktop.png` внутри проекта. Добавьте в README строку:

```markdown
![Deepspace в браузере](evidence/web-desktop.png)
```

7. Отправьте ещё три раза `2`, затем `NO`. Должны появиться `ENEMY VESSEL DESTROYED` и `TRY AGAIN LATER!`; поле ответа после завершения отключается.
8. Нажмите «Сохранить диалог»: должен скачаться текст. Нажмите «Начать заново»: должен появиться первый вопрос. Сузьте окно и проверьте читаемость. Длинные строки оригинала можно прокручивать внутри терминала.
9. После публикации проекта добавьте скриншот отдельным коммитом:

```sh
git add README.md evidence/web-desktop.png
git commit -m "Add screenshot from browser gameplay"
git push
```

Если страница не загрузилась, проверьте, что команда сервера всё ещё работает и открыт HTTP-адрес, а не файл HTML двойным щелчком. Если ошибка остаётся, пришлите её текст. В поставке проверены C и Wasm через автоматические диалоги; браузерный внешний вид не проверен, поскольку тестовый браузер в среде подготовки не запустился.
