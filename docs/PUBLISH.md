# Как опубликовать с историей

Подготовлен самостоятельный Git-репозиторий. В ZIP его служебная папка `.git` не включена. Настоящая история сохранена отдельно в `deepspace-history.bundle`.

1. Положите bundle в удобную папку и откройте там терминал.
2. Восстановите репозиторий в **новую** папку (не поверх распакованного ZIP):

```sh
git clone deepspace-history.bundle deepspace-git
cd deepspace-git
git log --oneline
```

3. На GitHub создайте **пустой публичный** репозиторий `deepspace`: без автоматически добавляемых README, лицензии и `.gitignore`.
4. Настройте имя и email для своих следующих коммитов. Существующие подготовительные коммиты имеют технического автора `Project preparation`; история не задним числом и не выдаётся за вашу самостоятельную работу.

```sh
git config user.name "Ваше имя"
git config user.email "Ваш email GitHub"
git remote add origin https://github.com/ВАШ_ЛОГИН/deepspace.git
git push -u origin main
```

Замените подписи своими данными. GitHub может попросить авторизацию. Проверьте, что в браузере видны исходники и история. Добавьте свой скриншот по SCREENSHOTS.md. Скопируйте ссылку преподавателю. Публикация не выполнена автоматически: для неё нужны ваш аккаунт и выбранный репозиторий.

Бинарные файлы не входят в Git-историю: они воспроизводятся сборкой. Готовый Wasm включён, чтобы веб-версию можно было запустить без установки Zig.
