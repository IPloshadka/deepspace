# Репозиторий проекта

Публичный адрес: https://github.com/IPloshadka/deepspace

Для дальнейшей работы с опубликованной историей:

```sh
git clone https://github.com/IPloshadka/deepspace.git
cd deepspace
git log --oneline
```

История локальной подготовки перенесена через GitHub API отдельными последовательными коммитами с исходными описаниями и ссылкой `Local-origin` на локальный SHA. Идентификаторы и даты удалённых коммитов отличаются: API создаёт их во время публикации от подключённого аккаунта. Это не задним числом и не утверждение самостоятельного авторства пользователя. Исходная локальная история сохранена в отдельном bundle.

Для новых изменений используйте клонированный репозиторий. Архив ZIP содержит файлы, но не `.git`. Скриншоты из CI можно скачать во вкладке Actions → завершённый запуск → web-screenshots и добавить в README. Настройка GitHub Pages не выполняется автоматически.
