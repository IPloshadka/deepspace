# Репозиторий проекта

Публичный адрес: https://github.com/IPloshadka/deepspace

Для дальнейшей работы с опубликованной историей:

```sh
git clone https://github.com/IPloshadka/deepspace.git
cd deepspace
git log --oneline
```

После первоначальной загрузки пользователем подготовленные этапные изменения перенесены обычным Git cherry-pick поверх существующей истории. Исходные авторы и даты этапов сохранены, идентификаторы коммитов изменились из-за других родителей. Публикация выполняется обычным Git без принудительной перезаписи истории. Подготовительные коммиты помечены техническим автором `Project preparation`; это не утверждение самостоятельного авторства пользователя.

Для новых изменений используйте клонированный репозиторий. Архив ZIP содержит файлы, но не `.git`. Скриншоты из CI можно скачать во вкладке Actions → завершённый запуск → web-screenshots и добавить в README. Настройка GitHub Pages не выполняется автоматически.
